# Vinay React Vite Portfolio

This is the React + Vite version of your portfolio, created specifically to avoid the Next.js localStorage runtime issue on your machine.

## Features
- Passport photo in hero card
- Intro section
- Two resume buttons
- Data Analyst and Data Scientist tracks
- GitHub public repos fetched automatically
- Dark modern UI

## Run
```bash
npm install
npm run dev
```

Then open the localhost URL shown in the terminal.
